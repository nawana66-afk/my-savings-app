存款目標小帳本 8.0 — 彩色分區＋易讀版面

更新內容：
- 新增首頁快速捷徑：快速記帳、分類預算、信用卡、收支明細。
- 目標存款採森林綠；記帳採淺紫；每月分類預算採暖米橘；信用卡採霧藍；本月生活費採淺綠；收支明細採粉灰；備份區採中性灰。
- 增加卡片區塊間距、輸入框觸控面積與手機版排版。分類超支仍使用紅字負數。
- 保留 7.0 所有功能，包括信用卡依帳單週期查詢、繳卡費、單卡明細、存款目標、分類預算及 JSON 備份還原。
- 此版本只改介面 CSS 與導覽，不修改 app.js 的計算邏輯或本機資料格式。

更新步驟：
1. 先在現有 App 點「備份 JSON」存到 iCloud Drive／檔案。
2. 解壓縮 ZIP，將八個檔案全部上傳至 GitHub 儲存庫 main 根目錄，覆蓋同名檔案。不要上傳 ZIP。
3. 等待 GitHub Pages 的 Actions 顯示綠勾勾。
4. 用 Safari 開啟原本網址，檢查首頁是否有四個快速捷徑與彩色分區；再開啟主畫面 App。
5. 若仍顯示舊版，請先檢查離線快取及部署，不要刪除 App 或清除網站資料，以免遺失紀錄。

此 App 將記帳資料存放在裝置本機儲存空間，沒有帳號同步；請定期 JSON 備份。
